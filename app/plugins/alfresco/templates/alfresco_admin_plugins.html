Uso negli incidenti

Quando il plugin è abilitato, nella sezione Documenti degli incidenti compare l’opzione per caricare i file anche su Alfresco. I documenti già collegati a un nodo Alfresco espongono download e cancellazione remota. Il pulsante Sync Alfresco nella sezione Documenti controlla soltanto l'esistenza dei node id remoti e aggiorna lo stato in CIR; non carica né ricrea file.

La cartella di ogni incidente include ID e nome leggibile, ad esempio incident-42 - Phishing account amministratore. Il report PDF automatico viene mantenuto direttamente nella stessa cartella con un nome coerente, ad esempio incident-42 - Phishing account amministratore - report.pdf. La visibilità del relativo checkbox e il suo valore predefinito per i nuovi incidenti sono configurati per tenant da Admin → Tenant. Il checkbox non viene mai mostrato quando il plugin Alfresco è disabilitato.

Configurazione amministrativa

  1. Seleziona il tenant attivo dal menu tenant e apri Admin → Plugins → Alfresco.
  2. Abilita il plugin e inserisci URL base e credenziali API dedicate a quel tenant.
  3. Imposta un Parent Node ID (UUID della cartella padre) oppure un Site; il Parent Node ID ha precedenza.
  4. Imposta la cartella destinazione e usa Salva e testa destinazione.
  5. Ripeti la configurazione per ciascun tenant: le credenziali e le destinazioni non vengono condivise tra tenant.

La cancellazione da CIR rimuove il nodo dal repository Alfresco secondo la policy di cancellazione del server (tipicamente cestino, non eliminazione permanente). Il record documento CIR resta disponibile. Il Sync è intenzionalmente read-only verso Alfresco.
