# RC70 - Incident creation instructional order

This editorial revision retains 85 slides and all existing vetted screenshots and synthetic illustrations. It reorders the six incident-opening slides after slide 14:

1. From the main incidents registry, start a new incident (slide 15).
2. Enter and save an incident manually, without a model (slide 16).
3. Understand what incident templates are, why they are useful, and which roles use/manage them (slide 17).
4. Create, edit and delete incident templates as tenant administrators (slide 18).
5. Derive an incident template from an existing incident (slide 19).
6. Create an incident using an available template and review prefilled fields before saving (slide 20).

The model-based path is intentionally taught only after the definition and administration of models. No application behavior was changed. The JSON addendum remains named `visual_rc69_addendum.json` to preserve the established CI references; the RC70 release replaces its content in place. The slide verifier now asserts the new order.
